Safety, Security & Emergency service is running

This service answers the API on port 8092 for S160 visitor management, S163 incident and near-miss reporting, and S174 emergency mass notification. It does not serve screens.

The visitor, incident and emergency screens are in the one SFL Operations dashboard, which calls this service from the browser.
